# Configure notification preferences

CheckBiz360 sends push and in-app notifications automatically when relevant events occur on the platform. Notifications arrive in the notification centre of the app (employees) or the back office (managers) with no prior configuration needed.

## Notifications the system sends automatically

The system generates notifications for the following types of event:

### For employees (mobile app)

| Event | Description |
|---|---|
| New document available | A document is assigned to the employee for consultation or read receipt |
| New task assigned | The manager assigns a task to the employee |
| Task validated or rejected | The manager issues the result of validating a completed task |
| Workday approved or rejected | The manager resolves a manual workday request |

### For managers (back office and app)

| Event | Description |
|---|---|
| Suspicious clock record | The system detects an irregular clock record on the team |
| Employee who has not clocked in | An employee with a shift has not recorded their entry |
| Manual workday pending approval | An employee has submitted a workday request requiring validation |
| Read receipt recorded | An employee has confirmed reading an assigned document |
| Task completed | An employee has marked a task as finished |
| Task not started on time | 15 minutes have passed since the expected start time without the task beginning |

---

## User-configured preferences

> **Status: Planned**
> This feature is part of the roadmap and is not available yet in the current version.

The possibility for each user to configure individually which notifications they want to receive or disable is planned for a future version. When it is available, it will allow employees to manage their preferences from the app and managers to configure the distribution of alerts among their team members from the back office.
