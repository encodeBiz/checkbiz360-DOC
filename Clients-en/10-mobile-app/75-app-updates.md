# App updates

Keeping CheckBiz360 updated to the most recent version is essential to guarantee compatibility with the server, the security of your account and access to the latest improvements and features. This article explains how to update the application on iOS and Android, the differences between automatic and manual updates, and the consequences of using an outdated version.

---

## Why keeping the app updated matters

Each new version of CheckBiz360 may include:

- **Security fixes**: patches protecting your account and your organisation's data against known vulnerabilities.
- **Server compatibility**: the CheckBiz360 server may require a minimum app version to process clock records and data requests correctly. An old version may stop communicating properly with the server.
- **Bug fixes**: improvements to the application's stability resolving problems detected in earlier versions.
- **New features**: access to new sections, configuration options or improvements to the clocking experience.

---

## How to update on iOS

### Manual update

1. Open the **App Store** application on your iPhone or iPad.
2. Tap your profile photo or account icon in the top right corner.
3. Scroll down to the **Available updates** section.
4. Find **CheckBiz360** in the list.
5. Tap the **Update** button next to the application.
6. Wait for the download and installation to finish. The application will update without needing to be reinstalled.

### Automatic updates on iOS

To enable automatic updates so that the app updates without manual intervention:

1. Open the system **Settings** application.
2. Scroll to **App Store**.
3. Turn on the **App Updates** switch.

With this option enabled, iOS will automatically download and install available updates when the device is connected to WiFi and plugged in to power.

---

## How to update on Android

### Manual update

1. Open the **Google Play Store** application.
2. Tap your account icon or the profile menu in the top right corner.
3. Tap **Manage apps and device**.
4. Tap the **Updates available** tab.
5. Find **CheckBiz360** in the list and tap the **Update** button.
6. Wait for the download and installation to finish.

You can also go there directly by searching for "CheckBiz360" in the Play Store and tapping **Update** if the button is available instead of "Open".

### Automatic updates on Android

To enable automatic updates in Google Play:

1. Open **Google Play Store** and search for **CheckBiz360**.
2. Tap the three-dot icon or the options menu on the app's page.
3. Select **Enable auto update**.

Alternatively, you can configure automatic updates globally from **Settings** inside the Google Play Store.

## What happens if an employee uses an outdated version

Using a very old version of CheckBiz360 can cause the following problems:

- **Clocking errors**: the server may reject requests coming from versions that are no longer compatible with the current communication protocols.
- **Error messages on signing in**: if the installed version is too old, the system may block access and show a notice requesting the update.
- **Outdated data**: old versions may not be able to display correctly the new information the server sends.
- **Security vulnerabilities**: earlier versions may contain security flaws that have already been fixed in later versions.

> **Warning:** If on opening the application you see a message indicating that your version is no longer supported or that you have to update it to continue, follow the update instructions described in this article before trying to use the app again.

---

## How the administrator can detect employees' versions

CheckBiz360 administrators and managers can consult from the web administration panel the version of the application each employee has installed on their device. This information is recorded automatically every time an employee clocks in or signs in.

From the web panel, the administrator can:

1. Go to the **Employee management** or **Devices** section.
2. Consult the column or field indicating the app version recorded for each user.
3. Identify the employees using versions earlier than the minimum recommended.
4. Get in touch with the employees affected so that they update the application.

> **Warning:** If you are an administrator and detect that a high percentage of your employees use outdated versions, consider sending an internal announcement reminding everyone of the importance of keeping the app updated. A failed clock record caused by version incompatibility can create attendance control incidents.

---

## Checking the installed version

To check which version of CheckBiz360 you currently have installed:

1. Open the application and sign in.
2. Go to the **Profile** section.
3. Scroll to the bottom of the screen, where the application's current version is usually shown alongside the build number.
